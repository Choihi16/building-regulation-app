# 🏛️ AI 건축 법규 분석 전문 에이전트 (Building Regulation AI Agent)

대지 위치(주소)를 입력받아 **국토교통부 브이월드(V-World) API**와 **법제처 국가법령정보공동활용(MOLEG) 자치법규 API**를 실시간 연동하여 대지 분석, 건폐율, 용적률, 최고높이, 4대 건축심의 규정을 정밀 분석해 주는 Streamlit 웹 애플리케이션입니다.

---

## 🚀 주요 기능

1. **대지 지적 및 용도지역 정밀 조회 (V-World API 2.0)**
   - 주소 입력 시 Geocoder 2.0 및 Search API를 통해 표준 19자리 **PNU(필지고유번호)**, 정제주소, WGS84 좌표(경위도), 행정구역 추출
   - 연속주제도 데이터 API(`LT_C_UQ111`, `LT_C_UQ112`, `LT_C_UQ113`, `LT_C_UQ114`)를 통한 용도지역(제3종일반주거지역, 일반상업지역 등) 실시간 판별
   - 지구단위계획구역(`LT_C_UPISUQ161`), 용도지구(`LT_C_UPISUQ151`), 토지거래허가구역(`LT_C_UQ141`) 등 중첩 규제 공간 분석

2. **지자체 조례 실시간 검색 및 본문 파싱 (법제처 Open API)**
   - 해당 지자체의 **도시계획조례** (서울특별시 도시계획 조례 등) 실시간 호출
   - 해당 지자체의 **건축조례** (서울특별시 건축 조례 등) 실시간 호출
   - 조례 본문에서 건폐율(제44조 등), 용적률(제48조 등), 최고높이(제33조/제35조), 건축위원회 심의 기준(제7조) 조문 원문 추출

3. **건축 규제 총괄 비교표 및 분석 리포트**
   - **건폐율 (BCR)**: 지자체 조례 상한 vs 국토계획법 시행령 상한 비교 및 완화 조항
   - **용적률 (FAR)**: 지자체 조례 상한 vs 국토계획법 시행령 상한 비교 및 인센티브(임대주택, 기부채납, ZEB 친환경 인증 등) 제시
   - **최고높이 제한**: 가로구역별 건축물 최고높이, 정북방향 일조권 사선제한(10m 이하 1.5m, 10m 초과 1/2) 분석
   - **4대 심의 규정 매뉴얼**:
     - 🏗️ **건축심의**: 광역(21층/10만㎡), 기초(분양 3,000㎡ 또는 30세대/오피스텔 50실 이상), 굴토심의(지하2층/10m)
     - 🚒 **소방심의/동의**: 건축허가 동의(연면적 400㎡ 이상), 성능위주설계(30층 또는 100m 이상, 연면적 20만㎡ 이상)
     - 🚗 **교통영향평가**: 용도별 연면적(공동주택 2만~3.6만㎡, 근린/판매 1.2만~1.5만㎡, 업무 2.5만㎡ 등)
     - 🌲 **경관심의**: 경관지구, 중점경관관리구역(7층/3,000㎡), 대형 건축물(30층/10만㎡)

4. **지구단위계획구역 / 재개발구역 특별 알림 배너**
   - 지구단위계획구역이나 재개발/재건축 구역일 경우:
     `⚠️ [중요 법적 안내] 지구단위계획 지침 별도 확인 필요`
   - 국토계획법 제54조에 따라 일반 조례보다 지구단위계획 결정고시 도서 및 시행지침이 법적으로 우선 적용됨을 강조 안내

5. **인터랙티브 위치도 & 리포트 내보내기**
   - 대지 좌표 기반의 지적 위치도 매핑
   - 전문 건축사 수준의 마크다운(.md) 보고서 원클릭 다운로드

## 🏃 실행 방법

### 방법 1: Windows 실행 배치 파일 더블 클릭
`run.bat` 파일을 실행하면 가상환경 활성화 및 Streamlit 서버가 자동 실행됩니다.

### 방법 2: 터미널 명령 실행
```powershell
cd "C:\Users\586\.gemini\antigravity\scratch\building-regulation-agent"
.\venv\Scripts\Activate.ps1
streamlit run app.py
```

브라우저에서 `http://localhost:8501`에 접속하여 이용할 수 있습니다.
